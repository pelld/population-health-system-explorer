# Population Health System Explorer

An interactive map for exploring how wider determinants, prevention, diagnosis, treatment, acute care, recovery and longer lives interact across the population health system.

The website separates:

1. **How the system might work** — plausible relationships, feedback loops and important unknowns.
2. **What we can measure** — observed values, partial proxies and missing information.

The initial release is an interactive prototype. Values in the evidence view are illustrative and are not attributed to a real ICB.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)`.

The published address will be:

`https://pelld.github.io/population-health-system-explorer/`

## Files

- `index.html` — page structure
- `style.css` — layout and visual design
- `data.js` — system relationships, interventions and prototype measures
- `app.js` — interaction and diagram behaviour
